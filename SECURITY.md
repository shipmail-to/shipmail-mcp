# Security policy

Report a vulnerability in the Shipmail MCP server, the hosted endpoint at
`https://shipmail.to/api/mcp`, or any other part of Shipmail to
[security@shipmail.to](mailto:security@shipmail.to). Do not open a public issue for it.

Include the affected component and version, the steps to reproduce, and what an attacker could do.
We confirm receipt and keep you updated until the issue is fixed.

Security fixes ship in the latest release on npm (`shipmail-mcp`) and on the hosted endpoint.
Older versions do not receive fixes.
